6.4 协作数据同步

  • • 4 个入口汇入同一个 sync_repository
  • • repo_id + GitHub ID：有则更新、无则新增
  • • PR 文件/评论整组替换
  • • CI 只给失败 Job 下载日志，保留结尾
  • • 只在最后 commit；不碰 RAG

6.5 Checkout

  • • managed：浅克隆到 .data/repos，可更新
  • • local：用户文件夹，只读不动
  • • 4 条 git 命令自动认出 owner/repo
  • • github / github_compatible 自动判断
  • • Token 不落盘（比原项目更安全）

6.5 项目预扫描

  • • 只读 README / docs / 依赖清单
  • • 跳过 node_modules，拦 .env 和私钥
  • • 指纹判断 ready / stale
  • • 不生成向量，Milvus 没开也能 ready
